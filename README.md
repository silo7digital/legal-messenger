# PSP Legal Messenger Demo

Interactive presentation prototype for a legal-document messenger service using Profit Share Partners' electric motorcycle fleet.

## Demo views
- Client booking and quotation
- Simulated live rider tracking
- Chain-of-custody timeline
- Proof-of-delivery state
- Rider mobile workflow
- Operations / dispatch dashboard
- Fleet and battery status

## Run locally
Open `index.html` in a modern browser.

This prototype uses simulated data. Live maps, real payments, authentication and backend services are not yet connected.
